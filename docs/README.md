# pwman Documentation

Welcome to the `pwman` documentation. `pwman` is a secure, command-line password
manager written in C++17 with a full-database encryption model and an interactive
terminal UI.

| [Usage](usage.md) | Every command, flags, and the interactive `list` UI keybindings |

| [Export & Import](export.md) | CSV/XML export and CSV import formats and their security implications |
